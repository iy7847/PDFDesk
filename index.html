! 외부 클라우드 변환 서버가 야기하는 기업 보안 리스크

전통적인 온라인 PDF 유틸리티 서비스들은 사용자의 파일을 중앙 서버로 전송받아 백엔드 리눅스 서버에서 ImageMagick, Ghostscript 등의 도구로 변환한 뒤 다시 다운로드 링크를 제공합니다. 이 과정에서 설계 도면, 원가 내역서, 비밀유지계약서(NDA) 등 핵심 기밀 데이터가 제3자의 서버에 일시적 또는 영구적으로 저장됩니다. 서버 관리자의 부주의, 데이터베이스 해킹, 클라우드 버킷 설정 오류 등으로 인한 기밀 유출 사고는 기업에 치명적인 법적 책임을 초래할 수 있습니다.

또한 유럽 GDPR이나 국내 개인정보보호법에서는 정보 주체의 명시적 동의 없는 제3자 국외 전송을 엄격히 규제하고 있어, 해외 클라우드 기반 PDF 변환기 사용 자체가 사내 컴플라이언스 위반이 되는 경우가 많습니다.

✓ KEP PDF의 해결책: 순수 WebAssembly & 메모리 샌드박스

KEP PDF는 이러한 근본적인 보안 위협을 해결하기 위해 서버리스 클라이언트 사이드 아키텍처(Client-Side Only Architecture)를 100% 구현했습니다. 최신 브라우저의 가상 머신 환경에서 구동되는 WebAssembly와 모던 HTML5 Canvas API를 통해, PDF의 파싱, 벡터 렌더링, 페이지 조작, 압축 인코딩 등 모든 고부하 연산이 사용자의 로컬 컴퓨터 메모리 샌드박스 안에서만 완료됩니다.

파일의 1바이트조차 네트워크 회선을 타고 외부로 나가지 않으므로, 인터넷 연결이 차단된 폐쇄망이나 엔터프라이즈 보안 사내망에서도 완전한 데이터 주권(Data Sovereignty)과 프라이버시를 완벽하게 보장받을 수 있습니다.

Help & FAQ

자주 묻는 질문 (FAQ)

KEP PDF 서비스의 보안, 라이선스, 대용량 처리 및 호환성에 대한 궁금증을 상세히 풀어드립니다.

Q1 업로드한 파일은 외부 서버로 유출될 위험이 전혀 없나요? expand_more

네, 전혀 없습니다. KEP PDF는 파일을 수신하는 백엔드 서버 자체가 존재하지 않습니다. 사용자가 문서를 드래그앤드롭하는 순간부터 모든 가공, 변환, 병합 처리는 오직 사용자 컴퓨터의 웹 브라우저 메모리 안에서만 일어납니다. 네트워크 개발자 도구(F12)를 열어 확인하셔도 파일 데이터가 외부로 발신되는 트래픽이 0임을 직접 검증하실 수 있습니다.

Q2 기업, 공공기관, 설계사무소에서 상업적으로 영구 무료 이용 가능한가요? expand_more

네, 개인 사용자뿐만 아니라 법인 기업, 관공서, 교육 기관 모두 100% 무료로 자유롭게 업무에 활용하실 수 있습니다. 유료 구독 결제나 회원가입 절차가 일절 없으며, 상업적 업무 문서 제작 및 관공서 인허가 납품용 서류 작성에도 제한 없이 사용 가능합니다.

Q3 대용량 도면 문서(50MB 이상)도 브라우저에서 처리가 가능한가요? expand_more

네, 최적화된 청크(Chunk) 스트리밍 처리 기술이 적용되어 대용량 문서도 원활하게 처리됩니다. 다만 웹 브라우저 프로세스에 할당된 가용 RAM 용량 한계가 있으므로, 단일 파일 기준 50MB 이내, 일괄 다중 작업 기준 총합 100MB 이내의 작업을 권장합니다. 메모리가 부족할 경우 페이지를 나누어 분할 처리하시면 안전합니다.

Q4 암호(보안)가 걸린 PDF 문서도 편집이나 리사이징이 가능한가요? expand_more

열기 암호나 편집 제한(권한 암호)이 걸려 있는 문서는 웹 브라우저의 PDF 보안 규정상 내부 스트림 읽기가 차단됩니다. 해당 문서의 암호를 PDF 뷰어 등에서 먼저 해제하신 후 파일을 업로드해 주시기 바랍니다.

Q5 어떤 브라우저 환경에서 가장 최적의 성능을 발휘하나요? expand_more

최신 웹 표준 기술(WebAssembly, Canvas 2D, Blob API)을 완벽히 지원하는 Google Chrome, Microsoft Edge, Safari, Naver Whale 브라우저의 최신 버전을 적극 권장합니다. 인터넷 익스플로러(IE)는 지원하지 않습니다.

Q6 오프라인 상태나 인터넷 연결이 끊겨도 작동하나요? (PWA 기술) expand_more

네, 가능합니다! KEP PDF는 프로그레시브 웹 앱(PWA) 표준을 준수합니다. 웹 브라우저 상단의 [앱 설치] 버튼을 누르면 PC나 모바일에 네이티브 데스크톱 앱처럼 설치되며, 서비스 워커(Service Worker)가 핵심 라이브러리를 로컬에 캐싱하므로 인터넷이 연결되지 않은 비행기 안이나 보안 현장에서도 모든 PDF 편집 기능이 완벽하게 작동합니다.

Q7 결과물 PDF에 사이트 로고나 강제 워터마크가 찍히나요? expand_more

전혀 찍히지 않습니다. KEP PDF는 무료 서비스임에도 불구하고 어떠한 서비스 홍보용 워터마크나 로고도 문서에 강제로 삽입하지 않습니다. 사용자가 의도한 원본 그대로의 순수한 문서만 깔끔하게 저장되므로 즉시 대외 발주처나 관공서에 제출하실 수 있습니다.

Q8 대형 도면 인쇄 및 플로터 출력 시 해상도가 깨지거나 손실되지 않나요? expand_more

도면 리사이징 및 단순 병합/분할 작업은 벡터(Vector) 좌표 데이터를 그대로 유지하므로 인쇄 시 선 굵기나 텍스트 해상도가 전혀 손실되지 않습니다. 단, 기밀 보안을 위한 '영구 마스킹(Flatten)' 기능의 경우 텍스트 복사를 방지하기 위해 캔버스 이미지로 변환되므로, 미리보기 화면에서 선명도를 확인하신 후 작업하시는 것을 권장합니다.

Q9 스마트폰이나 태블릿(iPad, 갤럭시 탭)에서도 이용할 수 있나요? expand_more

네, 완벽하게 지원합니다. KEP PDF는 반응형 웹(Responsive Web) 및 모바일 전용 하단 내비게이션 바를 기본 탑재하고 있어 모바일 사파리, 크롬 등 태블릿과 스마트폰 브라우저에서도 데스크톱과 동일한 편집 경험을 제공합니다.

Q10 향후 유료화되거나 기능 사용 횟수 제한이 생길 가능성이 있나요? expand_more

아닙니다. KEP PDF는 고가의 서버 연산 비용이 들지 않는 클라이언트 사이드 기술로 설계되었기 때문에, 트래픽이 폭증해도 서버 유지비가 발생하지 않습니다. 따라서 사용자에게 비용을 전가할 이유가 없으며, 영구히 100% 무료로 운영됩니다. 서비스 운영은 비침해적 웹 광고(Google AdSense)를 통해서만 건전하게 지속됩니다.
